# Compilador

Esse é um projeto de compilador feito em Python desenvolvido para concluir a matéria de Projeto de Compiladores.

# Compilar e executar
Na raiz do projeto, execute:

```
python main.py exemplos/valido.txt
```
O código objeto é salvo em saida/codigo-objeto.txt.

# Máquina
Para executar a máquina:
```
python Compilador/MaqHipo.py 
```
